# إعداد ربط أصوات الفصحى في SAWT AI

## ما الذي أصبح جاهزًا في التطبيق؟
- التطبيق يطلب قائمة الأصوات من `GET /v1/voices`.
- يقبل التطبيق معرّفات الأصوات التي تبدأ بـ `ar-XA-` فقط.
- عند اختيار صوت سحابي، يرسل النص إلى `POST /v1/synthesize` ويحفظ ملف MP3 مؤقتًا في مساحة التطبيق، ثم يشغله عبر خدمة الخلفية.
- تبقى أصوات الهاتف المحلية متاحة كخيار بديل.

## المطلوب لتفعيل المكتبة السحابية
1. انشر مجلد `backend` على Google Cloud Run وفق `backend/README_AR.md`.
2. اختبر عنوان الخادم بإضافة `/health` ثم `/v1/voices`.
3. افتح مستودع GitHub ثم: Settings → Secrets and variables → Actions → Variables → New repository variable.
4. الاسم: `SAWT_API_BASE_URL`
5. القيمة: رابط Cloud Run الأساسي فقط، مثل `https://اسم-الخدمة-....run.app` دون إضافة مسار API.
6. احفظ المتغير، ثم أعد تشغيل بناء التطبيق من Actions. سيقرأ سير العمل المتغير تلقائيًا.

إذا لم يُضف المتغير، سيظل التطبيق قابلًا للبناء وستظهر رسالة بأن مكتبة الفصحى السحابية غير مفعّلة.

## تنبيهات مهمة قبل النشر العام
- لا تضع مفاتيح Google Cloud أو ملفات حساب الخدمة في التطبيق أو مستودع GitHub.
- الخادم الحالي أساس أولي؛ أضف تسجيل دخول/مصادقة وحصص استخدام ومراقبة تكلفة قبل فتحه للجمهور.
- النص المرسل إلى الصوت السحابي يغادر الهاتف ويصل إلى خادم SAWT AI ومزوّد تحويل النص إلى كلام. وضّح ذلك للمستخدمين في سياسة الخصوصية.
- ملفات MP3 التي يولدها التطبيق تحفظ مؤقتًا داخل مساحة التطبيق. خيار تصدير ومشاركة الملفات بشكل دائم سيضاف في مرحلة لاحقة.
- لا يمكن ضمان أن أصوات الهاتف المحلية فصحى؛ مكتبة الخادم هي التي تقيد اللغة إلى `ar-XA`.
