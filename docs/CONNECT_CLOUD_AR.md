# ربط الخادم السحابي — SAWT AI

## الحالة الافتراضية
التطبيق لا يملك خادمًا عامًا مضبوطًا تلقائيًا. قيمة `SAWT_API_BASE_URL` فارغة افتراضيًا؛ لذلك لا يعمل التوليد السحابي في APK عادي حتى يُنشر الخادم ويُضبط عنوانه. النسخة الحالية لا تتضمن بعد محركًا محليًا كاملًا.

## متطلبات التفعيل
1. إنشاء مشروع Google Cloud.
2. تفعيل Cloud Text-to-Speech API والفوترة.
3. نشر مجلد `backend` على Cloud Run.
4. استخدام هوية خدمة Cloud Run بدلاً من وضع مفتاح خدمة داخل التطبيق أو GitHub.
5. اختبار `/health` و`/v1/voices`.
6. قبل أي استخدام عام، إضافة مصادقة وحصص استخدام وحدود تكلفة ومراقبة إساءة الاستخدام.
7. بعد تأمين الخادم فقط، ضبط متغير المستودع `SAWT_API_BASE_URL` من GitHub Actions Variables ثم إعادة بناء التطبيق.

## ما يفعله التطبيق
- يستعلم عن `GET /v1/voices`.
- يعرض أصوات `ar-XA` التي يعيدها الخادم وتملك نوع صوت رجاليًا أو نسائيًا.
- يرسل النص إلى `POST /v1/synthesize`.
- يتحقق من نوع الاستجابة الصوتية قبل حفظها وتشغيلها.
- يحد النص في الطلب الواحد إلى 5000 بايت UTF-8.
- يحفظ MP3 في مجلد Downloads/SAWT AI على Android 10 وما بعده. على الإصدارات الأقدم يستخدم مجلد ملفات التطبيق الخاص.

## تنبيه مالي وخصوصية
هذا خيار سحابي وليس دون إنترنت، وقد يترتب عليه رسوم بعد حدود الاستخدام المجاني لدى Google. النص يغادر الهاتف إلى خادم SAWT AI ومزوّد الخدمة. لا تفعل هذا المسار ما لم تكن مستعدًا لإدارة الفوترة والخصوصية والحماية. لا توجد مفاتيح خدمة داخل APK.
