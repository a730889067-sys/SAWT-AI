# SAWT AI — اتجاه المنتج

## الوعد
استوديو صوت متعدد اللغات يعمل محليًا بعد تنزيل النموذج. يجب وصف جودة العربية بدقة وعدم ضمان الفصحى الكاملة قبل مراجعة بشرية لعينات حقيقية.

## الأصوات المطلوبة
1. صوت رجالي واضح وعميق.
2. صوت نسائي واضح وطبيعي.
يستخدم التطبيق حاليًا Supertonic 3 بعشر هويات صوتية مرجعية: F1–F5 وM1–M5. هذه هويات أنثوية وذكورية وفق ملف النموذج، وليست بحد ذاتها إثباتًا أن النطق عربي فصيح 100%.

## مبادئ المنتج
- واجهة عربية RTL، داكنة وفاخرة، مباشرة وبأقل عدد ممكن من الخطوات.
- لا حساب ولا مفتاح API للتحويل المحلي.
- تنزيل النموذج عند الطلب بدل تضخيم APK.
- التحقق من المصدر والحجم وبصمة SHA-256 قبل استخدام الملفات.
- بعد تنزيل النموذج يجب أن يعمل التوليد دون إنترنت.
- لا اتصال سحابي افتراضي ولا مفاتيح سرية داخل APK.
- لا تستخدم أصوات نظام الهاتف بصمت ولا تدّعِ أن اللهجة أو النطق فصيح بالكامل دون اختبار.
- توفير التشغيل في الخلفية والحفظ وإدارة ملفات الصوت.

## المحرك الحالي
### Supertonic 3 عبر Sherpa-ONNX
- المحرك الفعلي في التطبيق هو SupertonicTtsEngine وليس Nabra.
- النموذج يدعم العربية والإنجليزية، ويحتوي عشرة متحدثين: IDs 0–4 = F1–F5، وIDs 5–9 = M1–M5.
- حزمة Sherpa-ONNX الرسمية مضغوطة، ويستبدل التطبيق ملف vector_estimator.int8.onnx بنسخة محسنة للأجهزة المحمولة من WilburDev/supertonic-3-mobile بعد التحقق من SHA-256.
- يستخدم إصدار 1.5.20 خطوتين للتوليد لإعطاء الأولوية للسرعة، مع عدد خيوط CPU وحجم دفعة متكيفين مع RAM المتاحة. قد تؤثر الخطوتان في نعومة الصوت مقارنة بخطوات أعلى، ويحتاج ذلك قياسًا على أجهزة فعلية.
- يدعم المحرك اللغتين عبر extra.lang = ar أو en. دعم العربية تقنيًا لا يعني ضمان تشكيل النص أو مخارج الحروف أو أسلوب الفصحى في كل نص.

## التشكيل التلقائي في الإصدار 1.5.20

- يستخدم مربع الكتابة نموذج Ichkil v0.3.0 لإضافة الحركات بعد توقف قصير عن الكتابة.
- ينزل النموذج (نحو 22.3 MB) عند أول استخدام ويعمل محليًا لاحقًا.
- تُحفظ الأسطر والمسافات وموضع المؤشر عند تطبيق الحركات.
- التشكيل احتمالي وليس تدقيقًا لغويًا نهائيًا؛ يلزم مراجعة الأسماء وأواخر الإعراب.
- يفرغ التطبيق عامل WebAssembly من الذاكرة قبل إنشاء الصوت لتقليل ذروة RAM.

## خارطة الطريق
- توثيق المصدر والترخيص وإصدارات كل ملف نموذج بدقة.
- اختبار كل صوت على جمل عربية موحدة ومشكولة وغير مشكولة، ومراجعة النطق بواسطة متحدثين متمكنين.
- قياس سرعة التحويل والذاكرة والحرارة على Android 11 منخفض الذاكرة، ثم ضبط عدد الخيوط وخطوات التوليد بناءً على القياس.
- اختبار التنزيل والاستئناف وفك الضغط والتحقق والعمل دون إنترنت.
- عدم اعتماد أي ادعاء «فصحى 100%» أو «سريع على كل الهواتف» دون نتائج قابلة للتكرار.

## شروط الجودة
- نجاح JVM tests وAndroid lint وبناء APK.
- التحقق من SHA-256 لكل ملف نموذج.
- مراجعة الحروف: ع، ح، ص، ض، ط، ظ، ث، ذ، ق، الهمزات والتنوين والأرقام والأسماء.
- التحقق من اختلاف الهوية بين الأصوات الرجالية والنسائية.
- اختبار نصوص قصيرة وطويلة، والحفظ والتشغيل في الخلفية وإعادة التشغيل بوضع الطيران.
- لا يصدر وعد بجودة أو سرعة محددة قبل الاختبار على الهاتف الفعلي.
