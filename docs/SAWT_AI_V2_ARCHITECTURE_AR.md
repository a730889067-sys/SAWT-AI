# SAWT AI v2 — المعمارية الجديدة ونطاق التنفيذ
تاريخ اعتماد البحث: 22 نوفمبر 2026

## الهدف
تطبيق Android واحد بحساب واحد للمستخدم، يجمع محركات TTS السحابية المسموح بها مجانًا في الفترة الحالية، مع مكتبة نماذج محلية قابلة للتنزيل. الأولوية لجودة العربية الفصحى ثم سرعة التوليد. لا يُفعّل أي محرك مدفوع ولا توجد ترقية تلقائية إلى خطة مدفوعة.

## هيكل النظام
1. تطبيق Android: واجهة عربية RTL، جلسة مستخدم واحدة، إدارة النصوص والتشكيل والتسجيلات، ومكتبة تنزيل الأصوات المحلية.
2. مصادقة التطبيق: Firebase Authentication. يسجل المستخدم مرة واحدة، ثم يحتفظ التطبيق بجلسة آمنة ويجدد الرمز عند الحاجة. لا يطلب التطبيق حسابًا لدى كل مزود TTS.
3. خادم SAWT: يتحقق من Firebase ID Token، ويتحقق من صلاحية كل مزود، ويخفي مفاتيح الشركات. لا يقبل أي مفتاح من داخل APK.
4. موزع TTS: يختار محرك الجودة أو السرعة أو الاحتياطي بحسب الوضع الذي يختاره المستخدم، ويبدّل تلقائيًا فقط عندما تكون الخدمة البديلة مهيأة ومجانية ومصرحًا بها.
5. مكتبة Offline: تنزيلات منفصلة قابلة للاستئناف والتحقق من SHA-256 قبل تثبيت النموذج. لا يُحذف سجل التسجيلات عند حذف نموذج صوتي.

## المحركات السحابية

### متاحة للتكامل المجاني بعد إعداد حساب المشغل
- EasyVoice API: صوتان عربيان محددان للفصحى ar_m1 (رجالي) وar_f1 (نسائي)، باستخدام محرك Supertonic-3؛ توضح وثائق API المفتوحة حصة 5,000 حرف يوميًا ومشاركة الحصة بين الموقع وAPI وعدم الحاجة إلى بطاقة دفع. صفحة الترخيص تذكر حقوق استخدام المخرجات في التطبيقات التجارية ضمن الخطط. لأن العربية beta ولوجود اختلاف بين صفحة API وصفحة الأسعار حول تفعيل الوصول، لن يُفعّل في النسخة العامة حتى يختبر المشغّل مفتاحًا مجانيًا فعليًا ويتأكد من الرؤوس والرصيد. 
- Google Gemini Developer API: gemini-3.8-flash-tts للجودة التعبيرية وgemini-3.8-flash-lite-tts لسرعة/حجم طلبات أكبر. الخطة المجانية لها حدود متغيرة، ومحتوى الطلبات المجانية قد يُستخدم لتحسين منتجات Google. لذلك يتطلب أول إرسال موافقة صريحة، ولا يرسل التطبيق نصوصًا سرية أو حساسة.
- Azure Speech F0: حصة منشورة 500,000 حرف Neural TTS شهريًا. لا يتم تفعيله إلا عندما يؤكد المشغل أن المورد نفسه على F0؛ أي مورد S0 يُرفض ولا يدخل التوجيه المجاني. الأصوات اليمنية ar-YE-SalehNeural وar-YE-MaryamNeural تحتاج مراجعة سمعية، وقد تحمل نبرة يمنية وليست صوتًا محايدًا بالكامل.

### تجريبي ومقيّد
- ElevenLabs Free: 10,000 رصيد شهري في الخطة المجانية، لكن مكتبة الأصوات غير متاحة عبر API للمستخدم المجاني، والخطة المجانية لا تمنح الترخيص التجاري. يُسمح فقط باختبار شخصي بمفتاح وVoice ID يضبطهما المشغل، مع إبقائه مغلقًا في النسخة العامة. لا نستخدمه كبديل في تطبيق منشور للجمهور ما لم يتغير الترخيص.
- Amazon Polly: خطة AWS المجانية تنطبق على العملاء الجدد ولمدة 12 شهرًا فقط وفق شروط Free Tier، مع حد شهري يختلف حسب نوع المحرك (حتى 5 ملايين حرف Standard و1 مليون Neural). يتطلب حساب AWS وإعداد بيانات اعتماد، لذلك لا يدخل في التوجيه الافتراضي؛ يمكن تفعيله لاحقًا فقط بعد تحقق المشغل من أهلية الحساب وتأكيد عدم وجود فوترة خارج الحصة.
- Google Cloud Text-to-Speech العادي: لا نعتمد عليه هنا لأن تجاوز الحصة المجانية قد يستوجب فوترة مفعلة ويولد رسومًا. لا نخلط بينه وبين Gemini Developer API.
- Hugging Face Inference Providers: الرصيد المجاني المنشور للمستخدم المجاني حاليًا 0.10 دولار شهريًا فقط وقابل للتغيير؛ ليس أساسًا مناسبًا لتطبيق مستمر.
- TTS.ai: يقدم نماذج Piper/VITS مجانية بحدود يومية، لكن المستوى المجاني للاستخدام الشخصي غير التجاري، لذلك لا يُستخدم كمحرك داخل إصدار عام. الأصوات العربية تشمل خيارات لهجية مثل Kareem؛ لا نفترض أنها فصحى محايدة.
- Fish Audio S2.1 Pro Free: خيار تجريبي متعدد اللغات، لكن نافذة الإتاحة المجانية المعلنة مؤقتة إلى 30 نوفمبر 2026، مع غياب SLA وغموض الترخيص للاستخدام العام؛ لا يدخل في التوجيه التلقائي.

## محركات غير معتمدة حاليًا
- OpenAI TTS API: خدمة API مدفوعة، فلا يتم إدراجها كخيار مجاني.
- Claude وKimi وMeta AI: لا نضيف واجهة الدردشة العامة كمحرك TTS؛ لا بد من واجهة TTS رسمية وشروط API تسمح بإعادة الاستخدام في التطبيق.
- Meta MMS Arabic TTS: ترخيص CC-BY-NC 4.0، لذلك لا يعاد توزيعه في منتج عام أو تجاري.

## مكتبة الأصوات Offline
### قابلة للاستخدام/الاختبار داخل المشروع الحالي
- Supertonic 3 عبر Sherpa-ONNX: المحرك المحلي الموجود في التطبيق الآن، مع أصوات مرجعية متعددة. لا يُعلن أنه فصيح 100% قبل اختبار كل عينة.
- Nabra-7M-Distill ONNX: حزمة عربية فصحى تجريبية بصوت نسائي واحد، موجودة في كتالوج المشروع الحالي؛ يجب الاستماع وقياس RAM/السرعة على الهاتف قبل اعتماده كصوت أساسي.

### مرشح جديد للمنصة
- SILMA TTS v1: أوزان Apache-2.0 وكود MIT، 150 مليون معامل، ويدعم العربية الفصحى والإنجليزية. التنفيذ المنشور مبني على F5-TTS/PyTorch، ولا توجد حاليًا حزمة Android ONNX مجربة في المشروع. لذلك يظهر «قيد تجهيز نسخة الهاتف» وليس زر تنزيل فعلي حتى نثبت إمكان تحويله وتشغيله على Android.
- Piper Arabic: تظهر عدة أصوات عربية، منها أصوات موصوفة بجودة عالية، لكن بعضها بلهجات أردنية/سعودية/إماراتية وبعض بطاقات الترخيص غير محددة. لن نوزع أي ملف قبل مراجعة ملف الترخيص والصوت نفسه.

## سياسة التنزيل
- عرض اسم النموذج، المصدر، الرخصة، اللغة/اللهجة، الجنس المعلن من ناشر الصوت، الحجم، SHA-256، ومتطلبات الذاكرة.
- تنزيل قابل للاستئناف. لا يثبت نموذج ناقص أو لا يطابق البصمة.
- عدم تنفيذ سكربتات قادمة من ملف الكتالوج؛ يصف الكتالوج بيانات الملفات فقط.
- إتاحة إلغاء/حذف النموذج واستعادة التحميل، مع الاحتفاظ بالسجل الصوتي.

## الجودة والسرعة
- الوضع الافتراضي: أعلى جودة مجتازة لاختبار النطق، لا أعلى اسم تجاري.
- خيار السرعة يستخدم النموذج الأسرع إذا ظلت الحروف العربية واضحة.
- اختبارات عينة ثابتة: الهمزات، ع/ح، ص/ض، ط/ظ، ث/ذ، ق، التنوين، الشدة، الأرقام، الأسماء، علامات الترقيم، النص المشكول وغير المشكول.
- يسجل Benchmark: أول تحويل بارد، تحويل دافئ، الزمن لكل 100 حرف، Real-Time Factor، الذاكرة PSS، وحجم الملف وحرارة الهاتف إن أمكن.
- لا يُكتب في وصف التطبيق «فصحى 100%» أو «فوري على كل الهواتف» دون نتائج فعلية من أجهزة حقيقية.

## الأمن والاستمرارية
- Firebase ID Token للتحقق من الحساب الواحد.
- مفاتيح المزودين على الخادم فقط.
- App Check وقيود API وسياسة خصوصية وموافقة قبل إرسال نص إلى جهة خارجية.
- حصة مشتركة ثابتة لكل مزود ومستخدم ويوم/شهر مطلوبة قبل فتح التطبيق للعامة. محدد المعدل الحالي في الذاكرة مؤقت للتطوير ولا يكفي لعدة نسخ خادم.
- لا يوجد fallback إلى مزود مدفوع. إذا نفدت كل الحصص السحابية، يبقى الصوت المحلي المحمّل متاحًا؛ وإذا لا يوجد صوت محلي، يظهر سبب مؤقت واضح بدل ادعاء النجاح.
