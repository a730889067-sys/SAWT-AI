# إعداد SAWT AI بالعربية

## 1. إنشاء حساب مجاني
افتح [موقع Sonex Labs](https://sonexlabs.com) وسجّل حسابًا جديدًا. بحسب وثائق الخدمة، يحصل الحساب الجديد على 10,000 حرف لتحويل النص إلى صوت دون الحاجة إلى بطاقة بنكية.

## 2. إنشاء مفتاح API
بعد تسجيل الدخول:
1. افتح قائمة **Configurations**.
2. اختر **Developer**.
3. افتح تبويب **API Keys**.
4. اضغط **Create key** واكتب اسمًا مثل SAWT AI.
5. انسخ المفتاح فورًا؛ قد لا يظهر مرة أخرى. يبدأ المفتاح عادةً بـ `vsk_`.

لا تضع المفتاح في تعليق GitHub أو ملف عام أو صورة ترسلها لأي شخص.

## 3. ربط التطبيق
1. افتح تطبيق SAWT AI.
2. اضغط **الإعدادات** من الشريط السفلي.
3. الصق المفتاح في خانة **مفتاح API**.
4. اضغط **حفظ وربط الأصوات**.
5. افتح تبويب **الأصوات** وانتظر تحميل قائمة الأصوات العربية.
6. اختر **Nour / نور** للصوت النسائي أو **Tariq / طارق** للصوت الرجالي، إذا ظهرا في حسابك.

## 4. التحويل والحفظ
ارجع إلى **الاستوديو**، اكتب النص، واضغط **استمع الآن**. بعد إنشاء الصوت سيظهر خيار **حفظ الصوت كملف MP3**، ويحفظه التطبيق داخل مجلد Downloads/SAWT AI.

## تنبيه حول المجاني
تذكر وثائق Sonex Labs أن الرصيد المجاني 10,000 حرف، وبعده يكون السعر المعلن 0.03125 دولار لكل 1,000 حرف. الخدمة قد تنتقل إلى الدفع حسب إعدادات الحساب والرصيد؛ لا تضف بطاقة أو رصيدًا، وتوقف عن الاستخدام عند انتهاء الرصيد المجاني إن كنت لا تريد أي تكلفة.

## الخصوصية
مفتاح API يحفظ في مساحة التطبيق الخاصة على هاتفك ولا يُرفع إلى مستودع GitHub. النص الذي تحوّله يُرسل إلى Sonex Labs لإنشاء الملف الصوتي؛ لا تستخدمه للنصوص الحساسة أو السرية.

## إذا لم تظهر الأصوات
تحقق من اتصال الإنترنت وصحة المفتاح، ثم أغلق التطبيق وافتحه من جديد. إذا ظهرت رسالة خطأ، أرسل صورة للرسالة فقط، مع إخفاء المفتاح وأي بيانات حساب شخصية.
