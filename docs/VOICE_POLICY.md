# SAWT AI voice policy

SAWT AI targets Modern Standard Arabic only (الفصحى), not regional dialect voices.

For the cloud catalogue, use Google Cloud TTS language code `ar-XA`, which Google's supported-voices documentation identifies as Modern Standard Arabic. The API filters the catalogue and validates every requested voice against this language code before synthesis.

The Android system TTS fallback can expose Arabic voices supplied by the device manufacturer. Those voices are not guaranteed to be Modern Standard Arabic, so they must be labeled as device-provided Arabic voices and must not be presented as the verified SAWT MSA catalogue.

Voice downloads:
- Cloud voices are streamed/generated by the provider and are not downloadable model packs.
- A separate downloadable offline voice-pack feature requires redistributable model files with explicit commercial-use licenses, model metadata, checksums, storage controls and on-device quality testing.
- Never ship a model without checking its license and verifying MSA pronunciation.
