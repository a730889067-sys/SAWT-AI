# SAWT AI

تطبيق عربي لتحويل النصوص إلى كلام مسموع، بواجهة RTL داكنة وعصرية.

## ميزات التطبيق
- تحويل النص العربي إلى صوت عبر الإنترنت.
- صوتان عربيان فصيحان من Sonex Labs: نور (نسائي) وطارق (رجالي)، بحسب الأصوات التي يوفرها حساب المستخدم.
- تشغيل الصوت داخل التطبيق وفي الخلفية.
- حفظ الصوت الناتج بصيغة MP3 في مجلد Downloads/SAWT AI.
- واجهة عربية كاملة، مع أيقونة SAWT AI المخصصة.
- لا يحتاج التطبيق إلى محرك نطق عربي مثبت مسبقًا على الهاتف.

## ربط خدمة الصوت
يستخدم التطبيق حساب Sonex Labs المجاني ومفتاح API الشخصي للمستخدم. توضح وثائق Sonex Labs أن التسجيل المجاني يتضمن 10,000 حرف لتحويل النص إلى كلام، دون الحاجة إلى بطاقة بنكية. بعد استهلاك الرصيد المجاني، تعلن الخدمة سعرًا قدره 0.03125 دولار لكل 1,000 حرف؛ لا تضف وسيلة دفع أو رصيدًا إلى حسابك ما لم تكن تريد ذلك.

خطوات الإعداد:
1. أنشئ حسابًا مجانيًا في [Sonex Labs](https://sonexlabs.com).
2. من لوحة الحساب افتح Configurations ثم Developer ثم API Keys، وأنشئ مفتاحًا جديدًا.
3. انسخ المفتاح فورًا؛ يظهر مرة واحدة ويبدأ عادةً بـ `vsk_`.
4. افتح SAWT AI، ثم الإعدادات، والصق المفتاح في خانة مفتاح API واضغط «حفظ وربط الأصوات».
5. افتح مكتبة الأصوات واختر نور أو طارق، ثم ارجع إلى الاستوديو للتحويل.

**مهم:** لا ترسل مفتاح API إلى أي شخص، ولا تضعه في GitHub. يُحفظ المفتاح في بيانات التطبيق الخاصة بالجهاز، ولا يُضمّن في ملف APK. لا تستخدم الخدمة لإرسال نصوص سرية؛ النص الذي تريد تحويله يرسل إلى Sonex Labs.

دليل عربي: [docs/SONEX_SETUP_AR.md](docs/SONEX_SETUP_AR.md).

## بناء APK
المتطلبات: JDK 17 وGradle 8.9 وAndroid SDK 35.
الأمر: `gradle assembleDebug`
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

ينشئ GitHub Actions ملف APK تجريبيًا تلقائيًا عند تحديث فرع التطوير أو طلب الدمج. نزّله من قسم Artifacts في صفحة تشغيل البناء.

## الخصوصية والأمان
التطبيق يتصل مباشرة بواجهة Sonex Labs من هاتف المستخدم باستخدام مفتاحه الشخصي. لا يرسل التطبيق هذا المفتاح إلى مستودع GitHub. يُرسل النص إلى Sonex Labs عند طلب إنشاء الصوت. تم تعطيل نسخ بيانات التطبيق الاحتياطية حتى لا يُدرج المفتاح ضمن النسخ الاحتياطية للنظام.

## حدود النسخة
- يتطلب تحويل النص اتصالًا بالإنترنت وحساب Sonex Labs ومفتاح API.
- الرصيد المجاني محدود بـ10,000 حرف وفق وثائق الخدمة وقد تتغير الشروط.
- بعد انتهاء الرصيد المجاني قد تُطبق رسوم الخدمة إذا كان الحساب يسمح بالدفع؛ لا تضف وسيلة دفع إن كنت تريد البقاء ضمن المجاني فقط.
- يجب اختبار الصوت على الهاتف بعد ربط المفتاح؛ لم يتم اختبار حساب المستخدم أو مفتاحه من داخل هذه البيئة.
- التطبيق ليس إصدارًا صوتيًا يعمل دون إنترنت.
