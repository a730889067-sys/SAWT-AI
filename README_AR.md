# SAWT AI — الإصدار 1.4.2

استوديو عربي لتحويل النص إلى صوت، بواجهة سوداء فاخرة ولمسات ذهبية واتجاه كتابة من اليمين إلى اليسار.

## ما أُضيف في هذه المرحلة
- محرر عربي مع عدّاد للأحرف والبايتات وحد أقصى 5000 بايت.
- محرك محلي تجريبي لصوت نسائي واحد بالعربية الفصحى الحديثة باستخدام Nabra-7M-Distill ONNX.
- رابط لتجربة صوت رجالي فصيح عبر مساحة Fasih الخارجية؛ يحتاج إنترنت ويفتح موقع التجربة خارج التطبيق، ولا يعمل دون إنترنت.
- تنزيل النموذج والتشكيل الآلي عند أول تجهيز، ثم تخزينهما في Cache Storage لإعادة الاستخدام دون إنترنت.
- إخراج WAV محليًا، مع تشغيله من خدمة Android وحفظه في مجلد التنزيلات.
- خيار سحابي منفصل اختياري لأصوات Google ar-XA الرجالية والنسائية، ويعيد MP3 عند إعداد الخادم.
- زر مساعدة عربي، وإظهار حالة التنزيل والتجهيز، وإمكانية حذف ملفات النموذج المحلية.
- لا نستخدم أصوات نظام الهاتف كبديل مخفي، ولا نخزن مفاتيح API داخل APK.

## تنبيه مهم قبل التثبيت
**محرك الصوت المحلي أصبح موصولًا بواجهة التطبيق في الكود، لكنه لم يجتز بعد اختبارًا فعليًا على هاتف Android 11.** يلزم اختبار تنزيل النموذج، وجودة النطق، واستهلاك الذاكرة، والسرعة، والتشغيل والحفظ، ثم وضع الطيران للتأكد من العمل دون شبكة بعد التنزيل.

الصوت المحلي الحالي **نسائي واحد فقط**. أضفنا رابطًا لصوت Fasih الرجالي بالفصحى عبر تجربة Hugging Face الخارجية؛ هذه خدمة إنترنت مستقلة وليست جزءًا من المحرك المحلي ولا نضمن توفرها دائمًا. نموذج Fasih نفسه مخصص لصوت رجالي بالفصحى لكنه مرخص للاستخدام غير التجاري فقط، ولا نضمّن أوزانه داخل APK. لا نغيّر طبقة الصوت لتقديم صوت نسائي على أنه رجالي.

## المحرك المحلي
- Nabra-7M-Distill ONNX: نموذج عربي فصيح حديث، صوت واحد، Apache-2.0. يستخدم التطبيق نسخة FP16 لتقليل حجم التنزيل.
- eSpeak-NG: لتحويل العربية إلى فونيمات؛ رخصته GPL-3.0-or-later، ويجب الحفاظ على الإشعارات ومتطلبات المصدر عند التوزيع.
- Ichkil: تشكيل آلي للنص العربي؛ النموذج يُنزّل عند أول تجهيز ويتحقق التطبيق من بصمته SHA-256.
- ONNX Runtime Web: تشغيل WASM محليًا داخل WebView.
- تنزيل النموذج والتشكيل يحتاج اتصالًا بالإنترنت في المرة الأولى. بعد اكتمال التخزين المؤقت، صُمم المحرك ليعمل دون شبكة؛ يجب تأكيد ذلك باختبار وضع الطيران.

## الخدمة السحابية الاختيارية
المجلد `backend` يحتوي خادم Google Cloud Text-to-Speech. ليس منشورًا تلقائيًا، ولا يوجد رابط خادم افتراضي داخل APK. يتطلب نشرًا آمنًا، وهوية خدمة، وتفعيل الفوترة لدى Google. قد تترتب عليه تكلفة، لذلك لا نعدّه مجانيًا بلا حدود. راجع `backend/README_AR.md`.

## البناء
- JDK 17
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Android SDK 35
- GitHub Actions يبني مكتبة Nabra من مصدرها الرسمي، ثم يحزم محرك WebView، ثم ينفذ Android lint وassembleDebug.

نجاح البناء لا يثبت جودة النطق أو سرعة الهاتف أو عمل وضع الطيران.

## فحوص الجودة المطلوبة قبل إصدار نهائي
- اختبار محرك الصوت النسائي على هاتف Android 11 فعلي.
- الاستماع للنطق العربي، خصوصًا ع، ح، ص، ض، ط، ظ، ث، ذ، ق والهمزات والتشكيل والأرقام.
- قياس زمن التحويل والذاكرة والحرارة على جهاز متوسط.
- اختبار التنزيل والاستئناف والتخزين، ثم إعادة التشغيل في وضع الطيران.
- اختبار WAV والحفظ والتشغيل المتكرر ومعالجة امتلاء التخزين.
- اعتماد نموذج رجالي منفصل بعد مراجعة ترخيصه وجودته وأدائه.
