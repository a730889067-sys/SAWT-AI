# SAWT AI

استوديو لتحويل النصوص إلى كلام باللغة العربية الفصحى، بواجهة عربية أولًا وتجربة استخدام هادئة وسريعة.

## النسخة التأسيسية 1.0.0
- واجهة Android حديثة باستخدام Kotlin وJetpack Compose.
- محرر نص عربي.
- اكتشاف الأصوات العربية المثبتة محليًا على الجهاز.
- اختيار الصوت وضبط السرعة وطبقة الصوت.
- تشغيل القراءة عبر خدمة أمامية لمواصلة التشغيل عند مغادرة الشاشة.
- إشعار للتحكم وإيقاف القراءة.
- لا يتم إرسال النصوص إلى خادم في هذه النسخة.

## البناء
المتطلبات: JDK 17 وGradle 8.9 وAndroid SDK 35.
الأمر: `gradle assembleDebug`
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## حدود النسخة الحالية
الأصوات المعروضة هي أصوات محرك Android المثبت على الهاتف، ويختلف عددها وجودتها حسب الجهاز. إدارة/تنزيل الأصوات يتم من إعدادات محرك الجهاز، وليس من خادم SAWT AI بعد.
هذه النسخة لا تتضمن بعد حزم أصوات مستقلة داخل التطبيق أو توليد MP3 أو مزامنة سحابية. لا تُعرض هذه الوظائف على أنها جاهزة قبل تنفيذها واختبارها.

## الخصوصية والتراخيص
في النسخة الحالية تتم معالجة النص محليًا عبر محرك النظام. يجب فحص تراخيص أي نموذج أو مزود صوت قبل تضمينه أو استخدامه تجاريًا.
