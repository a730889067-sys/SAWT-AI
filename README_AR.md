# SAWT AI

تطبيق تحويل النص إلى كلام بواجهة عربية RTL وهوية سوداء فاخرة ولمسات ذهبية.

## واجهة الإصدار 1.4.0
- تصميم داكن أسود مع لون ذهبي هادئ.
- واجهة مختصرة: محرر النص، اختيار الصوت الرجالي العميق أو النسائي الواضح، إنشاء الصوت، وحفظ MP3.
- لا توجد شاشة إعداد مفتاح API للمستخدم ولا يتم وضع أسرار داخل APK.
- لا تُعرض أصوات نظام الهاتف على أنها أصوات فصحى معتمدة.
- لا يظهر خيار صوت رجالي/نسائي إلا إذا أعاد خادم التطبيق صوتًا مطابقًا من قائمة العربية الفصحى الحديثة ar-XA.

## حالة الأصوات
التطبيق يتصل بعنوان خادم اختياري يحدد عبر Gradle property `SAWT_API_BASE_URL`. يجب إعداد الخادم وتمويل/ضبط خدمة التوليد قبل تفعيل الصوت السحابي. ملف backend الحالي يستخدم Google Cloud Text-to-Speech؛ وهو ليس خدمة مجانية غير محدودة. لا توجد حاليًا حزم محلية عربية فصحى مدمجة ومختبرة على أندرويد، ولذلك لا ندّعي أن التوليد المحلي أصبح جاهزًا.

## بناء APK
- JDK 17
- Gradle 8.9
- Android SDK 35
- `gradle assembleDebug`

ينشئ GitHub Actions ملف APK تجريبيًا تلقائيًا على فرع التطوير.

## دليل الاستخدام
أضيف زر مساعدة صغير في أعلى الواجهة يشرح كتابة النص واختيار الصوت وإنشاء التسجيل وحفظ MP3.

## فحص نماذج الأصوات الفصحى
- **Nabra-7M-Distill:** نموذج عربي فصيح (MSA) بحجم يقارب 28.7 MB، مع نسخة ONNX بحجم 16 MB تقريبًا ورخصة Apache-2.0. النموذج الموثق يحتوي على صوت واحد فقط، ولا يثبت وجود صوت رجالي ونسائي معًا. حزمة JavaScript الرسمية تعمل داخل المتصفح عبر ONNX Runtime Web؛ لم يتم اعتمادها بعد كمحرك أندرويد أصلي في هذا المشروع.
- **Fasih-TTS-V1:** صوت رجالي فصيح موثق، لكنه مبني على XTTS-v2 بحجم يقارب 466.9M مع رخصة Coqui Public Model License (غير تجارية). لا نضمّنه في إصدار قابل للتوزيع التجاري أو ندّعي أنه يعمل على الهاتف دون مراجعة ترخيصه وإجراء اختبار أداء أندرويد.
- **SILMA TTS:** يدعم الفصحى العربية والإنجليزية ورخصة أوزان Apache-2.0، لكن مسار التشغيل الموثق يعتمد Python/F5-TTS ولم يثبت بعد أنه مناسب للتشغيل المحلي على أجهزة أندرويد المستهدفة.

**قرار الجودة:** لا نعرض صوتًا على أنه مدمج أو متاح حتى يتم ربط المحرك فعليًا، وإنشاء ملف صوت، وفحص النطق والجودة على جهاز أندرويد. لا نستخدم صوت نظام الهاتف كبديل مخفي.
