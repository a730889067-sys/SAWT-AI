# SAWT AI — الإصدار 1.5.20

تطبيق Android لتحويل النص إلى صوت، مع واجهة أزرق داكن ولمسات ذهبية، وشاشة افتتاحية، وتشغيل التسجيلات وحفظها بصيغة WAV.

## المزايا

- تحويل النص محليًا على الهاتف بعد تنزيل محرك الصوت مرة واحدة.
- دعم العربية والإنجليزية ضمن إمكانات Supertonic 3.
- خمسة معرّفات أصوات رجالية (M1–M5) وخمسة معرّفات أصوات نسائية (F1–F5).
- تشكيل عربي تلقائي في مربع الكتابة: بعد التوقف القصير عن الكتابة، يضيف التطبيق الفتحة والضمة والكسرة والسكون والشدة والتنوين.
- معاينة قصيرة للصوت المحدد، مع الاحتفاظ بالعينات داخل جلسة التطبيق لتجنب إعادة توليد العينة نفسها.
- التحكم بسرعة القراءة من 0.8× إلى 1.2×، والبدء افتراضيًا بسرعة 1.2×.
- شاشة افتتاحية تحمل هوية SAWT AI قبل فتح استوديو التحويل.
- تشغيل التسجيل فور اكتماله، ثم إعادة الاستماع أو حفظ ملف WAV في مجلد التنزيلات / SAWT AI.
- استمرار التشغيل في الخلفية عبر خدمة تشغيل صوت.
- بعد تنزيل النموذجين أول مرة، يعمل تشكيل النص وتحويله إلى صوت محليًا دون اتصال.

هذا التطبيق مخصص لتحويل النص إلى صوت؛ لا يتضمن مساعد محادثة ولا يفهم الأسئلة أو يرد عليها مثل ChatGPT. ولا يعتمد التحويل المحلي على مفتاح API أو اشتراك.

## تنزيل الأصوات والتشكيل

يلزم اتصال بالإنترنت عند الاستخدام الأول لتنزيل مكوّنين مستقلين:

- **محرك الصوت:** نحو 133 ميجابايت لملفات Supertonic 3 السبعة. يُفضّل توفر 350 ميجابايت على الأقل أثناء التثبيت.
- **محرك التشكيل:** نموذج Ichkil v0.3.0 بحجم يقارب 22.3 ميجابايت. يُنزّل تلقائيًا عند أول كتابة نص عربي تتوقف بعدها قليلًا.

يتحقق التطبيق من بصمة SHA-256 لنموذج التشكيل قبل تشغيله، ويخزن النموذج محليًا. بعد اكتمال التنزيلين، لا يحتاج التشكيل أو إنشاء الصوت إلى اتصال بالإنترنت. النص الذي تكتبه لا يُرسل إلى خادم للتشكيل أو للتحويل المحلي.

## التشكيل التلقائي

1. اكتب أو الصق نصًا عربيًا في مربع الكتابة.
2. توقف عن الكتابة لحظة؛ يبدأ التطبيق بإضافة الحركات بعد مهلة قصيرة حتى لا يبطئ لوحة المفاتيح.
3. تظهر الحركات داخل مربع النص نفسه، ويُحافظ التطبيق على موضع المؤشر والأسطر.
4. يُرسل النص المشكول إلى محرك الصوت عند إنشاء التسجيل.

نموذج التشكيل آلي وليس مدققًا لغويًا معصومًا. قد يخطئ في أواخر الإعراب، وبعض الأسماء الأجنبية أو الكلمات التي تحتمل أكثر من قراءة. راجع النصوص المهمة أو الأسماء الحساسة قبل إنشاء الصوت، ويمكنك تعديل النص يدويًا.

## متابعة إنشاء الصوت

أثناء المعاينة أو إنشاء التسجيل تظهر بطاقة متابعة تتضمن:
- الوقت المتبقي التقريبي فقط، دون عرض الوقت المنقضي.
- مرحلة العمل الحالية، مثل تجهيز المحرك أو توليد الصوت أو حفظ الملف.
- مؤشرًا متحركًا يوضح أن العملية ما زالت تعمل.
- تقديرًا يتحسن بعد قياس زمن التحويل على هاتفك من عملية ناجحة سابقة.

في أول عملية، يبدأ التطبيق بتقدير الزمن بعد اكتمال أول مقطع صوتي. وفي العمليات التالية يستخدم الأداء المقاس سابقًا على الهاتف ويحدّث التقدير بعد كل مقطع. لا يستخدم التطبيق استدعاء JNI لإرسال أجزاء الصوت أثناء التوليد؛ اختيرت واجهة التوليد المباشرة لتجنب مسار callback الأصلي الذي قد يتسبب في إنهاء التطبيق على بعض التركيبات.

## طريقة الاستخدام

1. اتصل بالإنترنت وثبّت حزمة الأصوات من داخل التطبيق.
2. اكتب نصًا عربيًا؛ ستُضاف الحركات تلقائيًا بعد التوقف القصير. يلزم الإنترنت لتنزيل نموذج التشكيل أول مرة فقط.
3. اختر العربية أو English.
4. اختر أحد الأصوات M1–M5 أو F1–F5، ثم استمع إلى العينة.
5. اضبط سرعة القراءة إذا رغبت.
6. اضغط «إنشاء الصوت والاستماع».
7. استمع إلى النتيجة أو احفظ ملف WAV في مجلد التنزيلات / SAWT AI.

الحد الحالي للنص هو 2000 حرف في العملية الواحدة. يقسم التطبيق التشكيل داخليًا إلى مقاطع لا تتجاوز 900 حرف، ثم يقسم محرك الصوت النص إلى دفعات متوافقة مع ذاكرة الهاتف.

## تحسين الأداء والتوافق

- يستخدم التطبيق Supertonic 3 INT8 مع ملف vector estimator محسّن للأجهزة المحمولة.
- يستخدم خطوتين للتوليد لإعطاء الأولوية للسرعة؛ قد يؤثر خفض الخطوات في نعومة الصوت مقارنة بإعدادات أعلى.
- يختار عدد خيوط CPU ومقدار النص في كل دفعة وفق RAM الفعلية المتاحة وعدد أنوية المعالج. يصل إلى 2 خيط للأجهزة ذات RAM حتى 3GB، و3 للأجهزة حتى 6GB، وحتى 4 للأجهزة الأقوى؛ ويخفضها عند شح الذاكرة الحرة.
- يبدأ تجهيز محرك الصوت مسبقًا عند تشغيل الاستوديو لتقليل التأخير عند أول ضغطة.
- يكتب المقاطع الصوتية تدريجيًا إلى ملف WAV واحد لتقليل ذروة استهلاك الذاكرة.
- ينفذ عمليات التوليد والتثبيت بتسلسل يمنع التداخل، ويؤجل تحرير المحرك الأصلي حتى انتهاء العملية النشطة.
- يدعم APK واجهات ARM64 وARMv7 وx86_64، ويستهدف Android 8.0 وما بعده.
- لا يمكن ضمان زمن تحويل محدد لكل هاتف؛ فالسرعة تتأثر بمعالج الهاتف وRAM والحرارة والتخزين والتطبيقات الأخرى. مساحة التخزين الداخلية المتاحة ليست هي RAM.

## الخصوصية والتراخيص

بعد اكتمال تنزيل النماذج، يجري تشكيل النص وتوليد الصوت محليًا على الهاتف. يتصل التطبيق بالإنترنت عند تنزيل النموذجين أو تحديثهما فقط. راجع ملف THIRD_PARTY_NOTICES.md لتراخيص محرك الصوت ونموذج التشكيل ومحرك ONNX Runtime Web.

أوزان Supertonic 3 مرخصة بموجب OpenRAIL-M، بينما نموذج Ichkil v0.3.0 ومحرك ONNX Runtime Web مرخصان بموجب MIT. تختلف شروط الأوزان عن شروط كود المحرك؛ راجع ملفات التراخيص الأصلية قبل إعادة التوزيع.

## البناء والتحقق

- JDK 17
- Gradle 8.13
- Android Gradle Plugin 8.13.2
- Kotlin 2.3.10
- Android SDK 36 (Android 16)
- Sherpa-ONNX Android AAR v2.0.1
- Node.js 22 لبناء صفحة التشكيل المحلية وملفات WebAssembly.

ينفذ GitHub Actions اختبارات JVM، وفحص Android Lint، وبناء APK. يشمل الاختبار وظائف التوقيت، وسياسة عدد خيوط المعالجة وتقسيم النص وكتابة WAV وتجزئة نص التشكيل وتحريك المؤشر بعد إدراج الحركات. نجاح البناء يثبت قابلية التجميع والاختبارات الآلية فقط؛ ولا يثبت جودة النطق أو سرعة التحويل على كل هاتف.

## حدود الاختبار المعروفة

لا يزال يلزم اختبار الإصدار على هاتف Android فعلي للتأكد من:
- عمل WebView المحلي وتنزيل نموذج Ichkil أول مرة، ثم التشكيل دون إنترنت.
- نطق النص العربي بعد إضافة الحركات مع كل صوت.
- سرعة النصوص القصيرة والطويلة، واستهلاك RAM والحرارة.
- التشغيل في الخلفية وحفظ WAV وإعادة التشغيل.

لا يعلن المشروع اجتياز اختبارات الجهاز الفعلي قبل تسجيل نتائجها.
