# SAWT AI

استوديو عربي لتحويل النصوص إلى كلام مسموع، بواجهة RTL حديثة وتجربة استخدام سريعة.

## اتجاه التطبيق
- التطبيق يعتمد على الإنترنت للوصول إلى مكتبة الأصوات العربية الفصحى السحابية.
- الأصوات السحابية مقيدة باللغة العربية الفصحى (ar-XA)، مع إظهار الأصوات الرجالية والنسائية التي يوفرها مزود الخدمة.
- يمكن تشغيل الصوت في الخلفية وحفظ الناتج بصيغة MP3 في مجلد Downloads/SAWT AI.
- توجد أصوات محلية من محرك Android كخيار احتياطي؛ لا نضمن أن كل صوت محلي فصيح.
- أيقونة التطبيق المخصصة مبنية على علامة الموجة الصوتية الخاصة بـ SAWT AI.

## بناء APK
المتطلبات: JDK 17 وGradle 8.9 وAndroid SDK 35.
الأمر: `gradle assembleDebug`
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

يُبنى APK التجريبي تلقائيًا عبر GitHub Actions عند تحديث فرع التطوير أو فتح طلب الدمج.

## تفعيل الأصوات السحابية
1. نشر مجلد `backend` على Google Cloud Run ضمن مشروع يملكه المطور.
2. تفعيل Google Cloud Text-to-Speech وإعداد الفوترة وحدود الإنفاق.
3. ضبط متغير المستودع `SAWT_API_BASE_URL` في GitHub Actions على عنوان خدمة Cloud Run.
4. إعادة بناء التطبيق وتنزيل APK الناتج من GitHub Actions.

دليل الإعداد العربي: [docs/CONNECT_CLOUD_AR.md](docs/CONNECT_CLOUD_AR.md).

## الخصوصية والأمان
عند استخدام الصوت السحابي يُرسل النص إلى الخادم لتوليد الصوت. لا تضع مفاتيح Google Cloud أو بيانات اعتمادها داخل التطبيق أو مستودع GitHub. قبل الإطلاق العام يجب استكمال المصادقة، والحصص لكل مستخدم، ومكافحة إساءة الاستخدام، ومراقبة التكاليف.

## حدود النسخة الحالية
- خادم Google Cloud لم يُنشر تلقائيًا؛ يحتاج إلى مشروع وفوترة وصلاحيات يملكها المطور.
- حفظ MP3 لا يعني تنزيل نموذج صوت يعمل دون إنترنت.
- يجب نجاح بناء APK واختباره على هاتف فعلي قبل اعتباره إصدارًا نهائيًا.
- يجب مراجعة التراخيص والأسعار وشروط الاستخدام لدى مزود الصوت قبل الإطلاق التجاري.
