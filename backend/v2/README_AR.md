# SAWT AI v2 — خادم توجيه محركات الصوت

هذه نواة خادم جديدة، منفصلة عن خادم v1 القديم. لا تُفعّل أي محرك مدفوع تلقائيًا.

## الحالة الحالية
- مصادقة Firebase ID Token عبر التحقق من توقيع RS256 ومفاتيح Firebase العامة، مع التحقق من aud وiss وexp وiat وauth_time.
- كتالوج يوضح أي محركات مجانية مهيأة على الخادم دون كشف المفاتيح.
- Gemini 3.8 Flash TTS للجودة وGemini 3.8 Flash-Lite TTS للسرعة عبر Gemini Developer API.
- Azure Speech يُقبل فقط عند تأكيد F0 صراحةً؛ لا يُقبل S0 كخيار مجاني.
- ElevenLabs موجود كتجربة شخصية مشروطة، ولا يُتاح لتوزيع عام أو تجاري باستخدام الخطة المجانية.
- توجيه تلقائي مع انتقال احتياطي عند أخطاء الحصة أو التوفر، مع إبقاء الاختيار اليدوي على المحرك المحدد.
- حد للنص، تحقق من الصوت، وعدم تسجيل نصوص المستخدم.

## الإعداد
1. ثبّت Node.js 22 أو أحدث.
2. انسخ .env.example إلى .env في بيئة الخادم فقط.
3. أنشئ مشروع Firebase Authentication وفعّل تسجيل الدخول بالبريد/كلمة المرور أو Google. ضع Project ID في SAWT_FIREBASE_PROJECT_ID.
4. احصل على مفتاح Gemini Developer API وضعه في GEMINI_API_KEY داخل إعدادات أسرار الاستضافة، لا في APK أو Git.
5. اترك Azure وElevenLabs معطلين ما لم تتحقق من الأهلية والترخيص وحدود الخطة.
6. نفّذ npm test ثم npm start.

## المسارات
- GET /v2/health — حالة عامة لا تكشف الأسرار.
- GET /v2/providers — يتطلب Authorization: Bearer <Firebase ID token>.
- POST /v2/synthesize — يتطلب مصادقة Firebase، ويعيد ملف WAV/MP3.

مثال جسم الطلب:
{
  "text": "السَّلَامُ عَلَيْكُمْ",
  "provider": "auto",
  "voice": "female",
  "cloudDataConsent": true
}

cloudDataConsent مطلوب عند استخدام Gemini لأن الخطة المجانية تنص على أن المحتوى قد يُستخدم لتحسين منتجات Google. يجب أن تعرض واجهة Android هذا التنبيه بوضوح قبل أول إرسال.

## حدود مهمة قبل النشر العام
- حصص المزودين المجانية ليست غير محدودة، وتتغير وقد تتوقف عند بلوغ الحد.
- محدد المعدل الحالي في الذاكرة ومناسب لاختبارات النسخة الأولى فقط؛ قبل النشر العام متعدد الخوادم يجب نقله إلى مخزن مشترك دائم مع حصة يومية/شهرية لكل مستخدم ومراقبة للحصة العالمية.
- يلزم نشر الخادم على استضافة HTTPS، وضبط App Check/قيود تطبيق Firebase، وسياسة خصوصية وموافقة صريحة على إرسال النص إلى مزود خارجي.
- لا يوجد في هذا المستودع مفتاح API أو حساب استضافة جاهز. لا يمكن تفعيل السحابة قبل إعداد مفاتيح المالك ومشروع Firebase.
- لا تستخدم ElevenLabs Free في نسخة عامة أو تجارية: الخطة المجانية لا تمنح ترخيصًا تجاريًا ومكتبة الأصوات غير متاحة للمجاني عبر API.
- نجاح اختبارات الخادم لا يثبت جودة الصوت؛ يجب تكوين المفاتيح ثم توليد عينات عربية فصحى واختبارها سمعيًا.
