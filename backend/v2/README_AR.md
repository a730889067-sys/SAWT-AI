# SAWT AI v2 — خادم توجيه محركات الصوت

هذه خدمة الخادم الخاصة بميزة تحويل النص إلى صوت عبر الإنترنت. مفاتيح المزودين لا توضع داخل APK ولا في Git؛ تحفظ في متغيرات بيئة الاستضافة فقط.

## الحالة والتكامل

- EasyVoice: واجهة متوافقة مع OpenAI، ونموذج Kokoro-82M، وصوتان عربيان مجانيان على الخطة المجانية: `ar_m1` و`ar_f1`. الحد المنشور 5,000 حرف يوميًا مشترك مع موقع EasyVoice، ولا يتطلب بطاقة بنكية. يلزم إنشاء مفتاح API من حساب صاحب التطبيق. العربية موصوفة بأنها تجريبية، لذلك يجب سماع عينات فعلية قبل اعتمادها كأفضل صوت.
- Gemini 3.8 Flash TTS: نموذج مخصص لجودة النطق والتعبير، ومعرّف النموذج `gemini-3.8-flash-tts`.
- Gemini 3.8 Flash-Lite TTS: نموذج أسرع وأوفر للتوليد الاعتيادي، ومعرّفه `gemini-3.8-flash-lite-tts`.
- خطة Gemini المجانية لها حدود استخدام تتغير حسب الحساب/النموذج، وتوضح Google أن محتوى المستوى المجاني قد يستخدم لتحسين منتجاتها؛ لذلك يطلب التطبيق موافقة منفصلة قبل إرسال النص.
- ElevenLabs: موصل اختياري للاختبار الشخصي فقط. لا يفعّل في توزيع عام أو تجاري بالخطة المجانية؛ مكتبة الأصوات غير متاحة للمجاني عبر API والحقوق التجارية تتطلب خطة مدفوعة.
- Azure F0: موصل اختياري، لا يفعّل ما لم يثبت أن المورد F0 مجاني. لا يُفعل S0 على أنه مجاني.

> نجاح الاختبارات الآلية يثبت صحة منطق الطلب والاستجابة الوهمي، ولا يثبت بعد نجاح اتصال حساب حقيقي أو جودة عينة صوت عربية. يلزم مفتاح فعلي لاختبار الخدمة الحية.

## نشر الخادم مجانًا على Render

يوجد ملف `render.yaml` في جذر المستودع. من حساب Render:

1. افتح Render وأنشئ حسابًا مجانيًا، ثم اختر **New → Blueprint**.
2. اربط مستودع GitHub `a730889067-sys/SAWT-AI` واختر الفرع `redesign/sawt-ai-v2`.
3. دع Render يقرأ `render.yaml` وينشئ خدمة `sawt-ai-api` بالخطة المجانية.
4. أدخل قيم الأسرار في صفحة Environment للخدمة فقط:
   - `SAWT_FIREBASE_PROJECT_ID`: معرّف مشروع Firebase.
   - `EASYVOICE_API_KEY`: مفتاح EasyVoice الذي أنشأته من حسابك.
   - `GEMINI_API_KEY`: مفتاح Gemini API الذي أنشأته من Google AI Studio.
5. لا تغيّر `EASYVOICE_FREE_API_CONFIRMED` إلى `true` إلا بعد أن تتحقق أن المفتاح تابع للخطة المجانية وتقبل حد 5,000 حرف يوميًا.
6. لا تغيّر `GEMINI_FREE_TIER_CONFIRMED` إلى `true` إلا بعد التحقق من أن مشروع Gemini على المستوى المجاني وقبول سياسة استخدام بيانات المستوى المجاني.
7. انتظر نجاح Deploy، ثم افتح `https://YOUR-SERVICE.onrender.com/v2/health`. يجب أن يعرض `ok: true` و`authConfigured: true`.

Render Free لا يحتاج بطاقة بحسب دليل Render، لكنه يوقف خدمة الويب بعد 15 دقيقة من عدم النشاط، وقد يستغرق تشغيلها بعد الخمول نحو دقيقة. هو مناسب للتجربة وليس ضمانًا لخدمة إنتاج سريعة أو دائمة. راقب حدود الاستخدام؛ لا تفترض أن موارد الجهات الخارجية غير محدودة.

## إعداد Firebase

1. أنشئ مشروع Firebase مجانيًا.
2. فعّل Authentication ثم Email/Password.
3. أضف تطبيق Web داخل المشروع للحصول على Firebase Web API Key.
4. استخدم Project ID نفسه في `SAWT_FIREBASE_PROJECT_ID` في Render وGitHub.
5. لا ترسل مفاتيح API أو رموز الدخول داخل المحادثات أو ملفات المشروع.

## ربط عنوان الخادم بنسخة Android

بعد نشر Render، أضف في إعدادات مستودع GitHub:

**Settings → Secrets and variables → Actions**

- Repository variable: `SAWT_API_BASE_URL` = عنوان Render الذي يبدأ بـ `https://` دون / في النهاية.
- Repository variable: `SAWT_FIREBASE_PROJECT_ID` = Firebase Project ID.
- Repository secret: `SAWT_FIREBASE_WEB_API_KEY` = Firebase Web API Key.

ثم افتح **Actions → Build SAWT AI Android → Run workflow** لإنتاج APK جديد مرتبط بالخادم. لا تستخدم APK السابق لتجربة السحابة؛ فهو بُني قبل إعداد عنوان الخادم ومشروع Firebase.

## الأسرار والتنظيف

- لا تضع `EASYVOICE_API_KEY` أو `GEMINI_API_KEY` في Android أو BuildConfig أو مستودع GitHub.
- خزّن هذين المفتاحين في Environment الخاصة بخدمة Render فقط.
- يمكن إيقاف مزود بحذف مفتاحه أو تعطيل علم التأكيد. لكن حذف المفتاح نهائيًا يعني توقف ذلك المزود عن توليد الأصوات؛ لا يمكن حذف المفتاح مع استمرار نفس الخدمة بالعمل.
- إذا اضطررت لاختبار مفتاح في مكان غير آمن، ألغِه من لوحة المزود وولّد مفتاحًا جديدًا، ثم احتفظ بالجديد في أسرار الخادم فقط.

## المسارات

- `GET /v2/health` — حالة عامة لا تكشف الأسرار.
- `GET /v2/providers` — يتطلب Firebase ID Token.
- `POST /v2/synthesize` — يتطلب Firebase ID Token وموافقة البيانات عند استخدام Gemini.

مثال طلب:

```json
{
  "text": "السَّلَامُ عَلَيْكُمْ",
  "provider": "auto",
  "voice": "female",
  "cloudDataConsent": true
}
```

## حدود النسخة الحالية

- محدد طلبات المستخدم الحالي في ذاكرة عملية الخادم؛ لا يكفي وحده لحماية تطبيق عام متعدد النسخ.
- حصة EasyVoice المجانية مشتركة على مستوى المفتاح مع استعمال حساب EasyVoice خارج التطبيق، وقد تنفد قبل أن ينتهي اليوم.
- Render Free قد ينام بعد الخمول، لذلك أول تحويل بعد فترة توقف قد يتأخر.
- يلزم قبل النشر العام إضافة مخزن حصص دائم ومشترك، مراقبة، سياسة خصوصية، وقيود Firebase App Check.
