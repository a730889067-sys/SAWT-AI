# خادم SAWT AI الصوتي

خادم اختياري لتوليد MP3 باستخدام Google Cloud Text-to-Speech وأصوات العربية الفصحى الحديثة ذات رمز اللغة `ar-XA`.

## الحالة
هذا الخادم مصدر برمجي فقط؛ ليس منشورًا تلقائيًا ولا يوجد رابط تشغيل افتراضي داخل التطبيق. يحتاج Google Cloud Text-to-Speech إلى إعداد مشروع وهوية خدمة، كما يتطلب تفعيل الفوترة. لا تستخدمه على أنه خدمة مجانية غير محدودة.

## النشر
1. أنشئ مشروعًا في Google Cloud وفعّل Cloud Text-to-Speech API.
2. فعّل الفوترة وفق شروط Google.
3. انشر مجلد `backend` على Cloud Run.
4. امنح خدمة Cloud Run هوية خدمة بصلاحية استخدام Text-to-Speech.
5. لا تضع مفاتيح الخدمة أو ملفات JSON السرية في APK أو GitHub.
6. اختبر `/health` ثم `/v1/voices`.
7. لا تضبط `SAWT_API_BASE_URL` في بناء Android قبل تأمين الخدمة وإضافة المصادقة والحصص ومراقبة التكلفة.

## نقاط API
- `GET /health`
- `GET /v1/voices` — قائمة أصوات ar-XA التي يدعمها الخادم.
- `POST /v1/synthesize` — يستقبل النص ومعرّف الصوت ومعدل الإلقاء والطبقة، ويعيد MP3.

## حدود وحماية موجودة
- 5000 بايت كحد أقصى لكل نص، وليس 5000 حرفًا فقط.
- حد 5000 حرف احتياطيًا.
- تحديد معدل الطلبات لكل عنوان IP.
- تخزين مؤقت لقائمة الأصوات لمدة ساعة لتقليل طلبات الكتالوج.
- التحقق من أن الصوت المحدد موجود بالفعل في قائمة ar-XA.
- عدم تسجيل النصوص المرسلة عمدًا.

## متطلبات إضافية قبل فتح الخدمة للعامة
- أضف مصادقة مناسبة للتطبيق، وحصص استخدام للمستخدمين، وحدود تكلفة وفوترة وتنبيهات.
- أضف سياسة خصوصية واضحة؛ النص يغادر الهاتف ويصل إلى الخادم ثم مزود الخدمة.
- اختبر أسعار Google الحالية وحدودها قبل تفعيل الخدمة للمستخدمين.
