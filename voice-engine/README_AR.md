# محرك الصوت المحلي — SAWT AI

هذا المجلد يبني محركًا محليًا داخل Android WebView باستخدام Nabra-7M-Distill وONNX Runtime Web.

## الحزم والنماذج
- Nabra-7M-Distill-ONNX: صوت واحد `af_msa` للعربية الفصحى الحديثة، Apache-2.0، نموذج ONNX FP32 نحو 30.5 MB + حزمة صوت نحو 0.5 MB.
- nabra-tts 0.1.0: مكتبة JavaScript محلية؛ تُشغّل phonemization عبر eSpeak-NG WASM وتنتج PCM mono 24 kHz.
- eSpeak-NG 1.52 المضمن: GPL-3.0-or-later؛ يجب إبقاء إشعارات المصدر والترخيص وتوفير المصدر المطابق عند توزيع التطبيق.
- Ichkil v0.3.0: تشكيل آلي عربي، MIT، ملف ONNX نحو 22.3 MB؛ يتحقق محرك التنزيل من SHA-256 قبل التخزين المؤقت.
- ONNX Runtime Web 1.30.0: MIT.

الحجم المتوقع لأول تنزيل للنماذج حوالي 53 MB، إضافة إلى مكتبات WASM المرفقة داخل APK. هذا تقدير لحجم الملفات لا قياسًا لاستهلاك البيانات الفعلي.

## طريقة التشغيل
1. يفتح Android WebView الصفحة المحلية عبر WebViewAssetLoader على أصل HTTPS محلي.
2. تُنزّل حزمة Nabra وحزمة Ichkil مرة واحدة إلى Cache Storage.
3. يتحقق Ichkil من SHA-256 للنموذج قبل استخدامه.
4. يضيف Ichkil التشكيل إلى مقاطع النص غير المشكول، ثم يحول Nabra النص إلى فونيمات ويولد صوتًا.
5. تُرسل عينات PCM 16-bit على دفعات إلى طبقة Android الأصلية، التي تكتب WAV محليًا وتشغله بخدمة التشغيل.
6. بعد وجود الملفات في Cache Storage يجب أن يكون التشغيل دون شبكة؛ يجب اختبار ذلك فعليًا بوضع الطيران على أجهزة حقيقية.

## بناء
من GitHub Actions:
`npm install --no-audit --no-fund` داخل هذا المجلد ثم `npm run build`.
يُنسخ الناتج مباشرة إلى `app/src/main/assets/voice_engine`، وتُنسخ ملفات ONNX Runtime WASM إلى `wasm/`.

## حدود معروفة
- هذه الحزمة تُقدّم صوتًا نسائيًا واحدًا فقط؛ لا تُنتج صوتًا رجاليًا.
- لا تغير pitch لتحويل الصوت النسائي إلى رجالي.
- التشكيل الآلي قد يخطئ في الأسماء والهمزات والسياق والإعراب؛ راجع الصوت.
- WebView/WASM يجب اختباره على Android 11 وعلى هاتف المستخدم. لا يوجد حتى الآن قياس موثوق للسرعة أو الذاكرة على ذلك الجهاز.
- أول استخدام يحتاج اتصال إنترنت لتنزيل الحزمتين. لا توجد رسوم API أو خدمة سحابية؛ التنزيل من مستودعات عامة.
