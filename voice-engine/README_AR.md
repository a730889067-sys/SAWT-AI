# محرك الصوت المحلي — SAWT AI

يحتوي هذا المسار على صفحتين محليتين تُبنيان داخل APK:
- `index.html`: محرك Nabra-7M-Distill لصوت عربي واحد في الفصحى الحديثة.
- `tashkeel.html`: واجهة Ichkil للتشكيل التلقائي المستخدم في محرر Android.

## حزم الأصوات
- **Supertonic 3** هو المحرك الأساسي من Sherpa-ONNX داخل Android، مع 10 هويات صوتية ويعمل محليًا بعد تنزيل النموذج.
- **Nabra-7M-Distill-ONNX** حزمة اختيارية تضاف من مكتبة الأصوات. النموذج يوفر حاليًا هوية صوتية عربية فصحى واحدة فقط، وليس أصواتًا رجالية ونسائية متعددة. يستخدم الإصدار FP16 بحجم معلن 16 MB، وملف الصوت نحو 0.5 MB، ويخرج 24 kHz mono.
- تثبيت Nabra يتم عبر `nabra-tts` 0.1.0، مع تثبيت مستودع النموذج على commit SHA محدد. بعد التنزيل والتخزين المؤقت يعمل محليًا.

## الحماية والتشغيل
- لا تُقبل حزم صوت من ملف JS خارجي؛ كتالوج GitHub يحتوي بيانات فقط، ويُقيّد Android المستودع بمحرك Nabra المعروف ويطلب commit SHA ثابتًا.
- ملفات واجهة JS وWASM تبنى داخل APK، ولا تستخدم CDN لتشغيل ONNX Runtime.
- تنزيل نموذج الصوت يتم عبر HTTPS من مستودع Hugging Face الثابت. يظل الاتصال مطلوبًا أول مرة؛ بعد التخزين المؤقت يعمل الصوت محليًا.
- لا يوجد حتى الآن اختبار سرعة/ذاكرة أو مراجعة استماع بشرية لـ Nabra على جهاز Android مستهدف. لذلك يظهر في المكتبة كصوت تجريبي إلى أن ينجح هذا الاختبار.
